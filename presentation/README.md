# Hohenheim AD Modelling Presentation

This folder contains the animated single-file HTML presentation prepared for a research discussion with Dr. Benedikt Hülsemann at the University of Hohenheim.

The deck connects the Biochar–AD Digital Twin with a proposed cross-study modelling framework designed to separate material effects from inoculum and operating-condition effects. It also describes the time-resolved experimental data required for validation and possible collaboration.

## Open locally

Download `index.html` and open it in a modern web browser. No installation or build step is required. Use the left and right arrow keys to change slides and press `F` for fullscreen.

## Edit and publish

Edit `index.html`, commit the change to `main`, and refresh the GitHub Pages URL after the deployment completes. Deliberate placeholders in square brackets should remain until verified information is available.
