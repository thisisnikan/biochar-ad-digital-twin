The problem

One number per curve hides the mechanism

Batch BMP studies usually report a single cumulative-methane endpoint per treatment. That endpoint carries dose, temperature, substrate, inoculum and reactor effects all at once, with no way to tell them apart.

A single number cannot say whether an additive made digestion faster or made it produce more — and it cannot be checked against an independent dataset.
The question

Does explicitly modelling biochar dose and temperature explain and predict methane production better than a condition-agnostic baseline?

The hypothesis is written to fail: a shared dose–temperature model must beat a simple three-parameter Gompertz baseline on held-out batches, or it is rejected. That falsifiability is the point — the repository is built to test the idea, not to assume it.

What is built

An installable, tested modelling pipeline — not a notebook

STAGE 01

Curated inputs

Time-resolved BMP curves — labelled synthetic demonstration data plus dataset-specific experimental benchmarks, each tagged with provenance.

STAGE 02

Global kinetic fit

Modified Gompertz methane kinetics with an explicit, smooth dose response and a Q10 temperature correction, fit by robust global least squares across every condition at once.

STAGE 03

Uncertainty & baselines

Batch-aware residual bootstrap for parameter uncertainty, compared against a parsimonious constant-Gompertz baseline using AIC, AICc and BIC.

STAGE 04

Held-out validation

Leave-one-batch-out prediction error separates curve fitting from genuine predictive skill — the check that decides whether the model has earned the claim.

Every stage runs from one command and produces reproducible CSV, JSON and publication-ready PNG outputs.
Try it

The whole workflow, end to end, in one command

python -m venv .venv source .venv/bin/activate pip install -e ".[dev]" biochar-ad demo --output outputs --bootstrap 100

Produces the synthetic input, fitted parameters, bootstrap uncertainty, baseline comparison and leave-one-batch-out error — every claim in this deck can be regenerated from the public repository.

Evidence already assembled

Three layers of evidence, kept explicitly separate

Software demonstration

Labelled synthetic BMP curves. Proves the end-to-end fitting, uncertainty and held-out-batch workflow runs correctly. Does not prove scientific validity — the data is synthetic by design.

Reactor-level benchmark

Kozłowski et al. (2025), 12 food-waste reactor trajectories, openly licensed (CC BY 4.0). Supports a reproducible kinetic-family comparison. Does not support a universal biochar mechanism — one temperature, one dose per treatment.

Author-shared summary analysis

Zhang et al. (2022), treatment means and standard deviations, ingested with a hash-verified private script. Supports kinetic/VFA analysis with explicit limitations. Does not support replicate-held-out validation — the original triplicates were lost.

Nothing here claims more than its dataset can support. That boundary is documented and reviewed on every change, in docs/PROJECT_STATUS.md.
Honest status

What can and cannot be claimed right now

  • Can claim: the software executes an auditable, reproducible end-to-end BMP workflow.
  • Can claim: modified Gompertz has the lowest mean reactor-held-out RMSE within each treatment of the included open benchmark.
  • Can claim: author-shared summaries can be analysed without inventing pseudo-replicates or publishing private data.
  • Cannot claim: that biochar causally improves anaerobic digestion across studies.
  • Cannot claim: that the dose–temperature response generalises beyond the demonstration.
  • Cannot claim: that this is already an operational plant digital twin.
This is a reproducible research prototype for falsifiable kinetic modelling, described that way on purpose — not yet a validated predictive product.

Roadmap

The next validation gate

  1. Reactor-level methane or biogas trajectories.

    Not summary endpoints — the kinetic parameters need real curves.

  2. At least three biochar doses and more than one temperature.

    The current open benchmark has one of each; the dose–temperature hypothesis needs a range.

  3. Biological or reactor replicates, plus inoculum-only controls.

    To separate real treatment effects from batch-to-batch scatter.

  4. Substrate, inoculum, S/I ratio, reactor and material metadata.

    The confounders that make cross-study comparison meaningful instead of misleading.

  5. A preregistered held-out-study comparison against parsimonious baselines.

    So the model can fail publicly, not just succeed quietly.
Why it matters

A framework built to be proven wrong, not just published

If the dose–temperature hypothesis survives independent, multi-condition reactor data, the same framework can guide which material and dose is worth testing before anyone runs a batch. If it does not survive, that negative result is written into the repository, not hidden by it — and it still tells the field what its data can and cannot support.

Ongoing conversations, including with Dr. Benedikt Hülsemann at the University of Hohenheim, are aimed at closing exactly this data gap.
Take-aways

Three things worth remembering

  1. It is a reproducible, tested software pipeline today — not a validated causal model of biochar effects yet.

  2. Every claim is scoped to its evidence, in the open, and re-checked on every change.

  3. What it needs next is independent, multi-dose, multi-temperature reactor data with intact replicates.
